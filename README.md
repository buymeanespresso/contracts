# Buy Me an Espresso

Buy Me an Espresso is a decentralized cross-chain creator tipping platform built on an Arbitrum Orbit Rollup integrated with the Espresso Network. The platform enables seamless cross-chain tipping using the ERC-7683 intents standard.

## Overview

Our platform allows:
- Creators to receive tips across multiple chains
- Tippers to send tokens from one chain to a creator on another chain
- Cross-chain message verification through the Espresso Network
- Intent-based transactions using the ERC-7683 standard
- Membership tier creation and subscription for creators
- AI agent profiles with revenue splitting for autonomous agents

## Architecture

- **Smart Contracts**: Solidity contracts for the tipping platform, including:
  - Base7683 (ERC-7683 base implementation)
  - TipIntent (Cross-chain tipping implementation)
  - IntentSolver (for executing intents)
  - HotShotVerifier (for cross-chain message verification)
  - EspressoCreatorRegistry (for creator profiles)
  - EspressoMembership (for membership tier management)
  - AICreatorExtension (for AI agent registration and revenue splitting)
  
- **Cross-Chain Messaging**: Powered by Espresso Network's HotShotVerifier

- **Intent Standard**: Implementation of ERC-7683 Open Intents Framework

## Cross-Chain Messaging Flow

The platform implements a direct contract-based cross-chain messaging flow:

1. User creates a tip intent on the source chain
2. A message ID is generated by the HotShotVerifier
3. The message is confirmed through the HotShotVerifier
4. Once confirmed, the intent solver executes the tip on the destination chain

For a detailed, production-ready implementation guide with complete code examples, see our [Cross-Chain User Flow](./cross-chain-user-flow.md) document.

```typescript
// Generate message ID
const messageId = await hotShotVerifier.generateMessageId(
  ethers.solidityPacked(
    ["address", "address", "address", "uint256", "uint256"],
    [sender, recipient, token, amount, nonce]
  )
);

// Confirm message
const tx = await hotShotVerifier.confirmMessage(messageId);
await tx.wait();

// Execute intent
const executeTx = await intentSolver.solveIntent(intentId, messageId);
```

## Creator Membership Features

The EspressoMembership contract allows creators to:

1. Create membership tiers with customizable:
   - Pricing
   - Duration
   - Benefits and perks

2. Manage subscribers and memberships through:
   - Automatic renewal tracking
   - Membership status verification
   - Cancellation options

```typescript
// Creating a tier
const tierPrice = ethers.parseEther("0.1"); // 0.1 ETH
const tierDuration = 30 * 24 * 60 * 60; // 30 days in seconds
await membershipContract.createTier(
  "Gold Tier",
  "Premium content access",
  tierPrice,
  tierDuration,
  ["Exclusive content", "Priority support"]
);

// Purchasing a membership
await membershipContract.purchaseMembership(creatorAddress, tierId, { value: tierPrice });
```

## AI Agent Integration

The AICreatorExtension contract enables:

1. AI agents as first-class creators with:
   - Different agent types (Autonomous, SemiAutonomous, Controlled)
   - Training information and capabilities

2. Automatic revenue splitting between:
   - Developers (who built the AI)
   - Operators (who run the infrastructure)

```typescript
// Registering an AI agent
await aiExtensionContract.registerAsAgent(
  1, // Autonomous
  developerAddress,
  operatorAddress,
  5000, // 50% split to developer
  "Trained on custom data",
  "Content creation, personalized responses"
);
```

## Setup and Development

### Prerequisites

- Node.js v18+
- Bun package manager
- MetaMask or another Ethereum wallet

### Verified Contracts

All core contracts have been verified and are considered stable for production use. For a detailed list of verified contracts, testing details, and known limitations, see the [Verified Contracts](./lts_verified_contracts.md) document.

### Installation

1. Clone the repository:
```bash
git clone https://github.com/buymeanespresso-contract.git
cd buymeanespresso-contract
```

2. Install dependencies:
```bash
bun install
```

3. Set up environment variables:
```bash
cp .env.example .env
# Edit .env with your configuration
```

### Running Tests

Run the production integration test:
```bash
bun run test:production
```

This will:
- Connect to the source chain (Espresso Rollup)
- Connect to the destination chain (Arbitrum Sepolia)
- Create a cross-chain tip intent
- Generate and confirm a message with the HotShotVerifier
- Execute the cross-chain tip

Verify the Espresso Network integration:
```bash
bun run verify:espresso
```

Test the membership functionality:
```bash
bun run test:membership
```

Test the AI agent functionality:
```bash
bun run test:ai-agent
```

Run all unit tests:
```bash
bun run test:unit
```
